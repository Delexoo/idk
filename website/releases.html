Release notes

What changed

Every version is listed here, with what was added and what was fixed.

v0.1.11 Latest 2 Nov 2026

Simpler dashboard

Added

Dashboard

  • The home page is a title, one status line, and the chat list, and the other pages use plain rows.

Site

  • The site lists what changed in every version.

Overlay

  • With the search bar locked at the bottom center, the answer card stays there.

Bug fixes

Overlay

  • The answer card bottom corners are rounded.
  • An ask answers the selected text instead of describing the screenshot.
v0.1.9 2 Nov 2026

Button hover fills the control

Bug fixes

Dashboard

  • Hover tint covers the whole button.
v0.1.8 2 Nov 2026

Slimmer answer card

Added

Overlay

  • The answer card is slimmer and shows the highlighted text as a small raised preview.

Chat

  • A saved chat shows the highlighted text as a small raised preview.
v0.1.7 2 Nov 2026

Checkout confirmation

Added

Dashboard

  • After checkout, a short confirmation says this computer is subscribed.
  • Send feedback is gone from the dashboard.
v0.1.6 2 Nov 2026

Promo codes stay on Stripe

Added

Dashboard

  • A promotional code is entered on the Stripe checkout screen.
v0.1.5 2 Nov 2026

Five free asks, then Billing

Added

Dashboard

  • Billing shows how many free asks are left and upgrades this computer to idk Pro.

Overlay

  • The first 5 asks are free. After that, Upgrade opens Billing.

Bug fixes

Overlay

  • An ask still answers when the screenshot model is unavailable.
v0.1.4 2 Nov 2026

The ask bar is a smooth capsule

Added

Dashboard

  • Settings sells idk Pro for $3 a month, and asking stays on while that subscription is active.

Site

  • The site lists idk Pro at $3 a month.

Bug fixes

Overlay

  • The ask bar is a smooth capsule, with sharp text and rounded ends.
v0.1.3 2 Nov 2026

Dashboard responds to the pointer

Added

Dashboard

  • Sidebar, buttons, switches, rows, and cards light up and press in when you hover or click.
  • Settings lets the search bar follow the cursor, or locks the mini search bar at the bottom center of the screen.
  • How to use includes a short paragraph you can highlight to try the ask bar.
  • Settings can keep idk off screenshots, screen shares, and streams.
v0.1.2 2 Nov 2026

Selection opens the ask bar

Bug fixes

Overlay

  • Selecting text in an editor or browser opens the ask bar, and the bar stays up after it takes focus.
  • Shift + select opens the ask bar when Shift was held during the drag.
v0.1.1 2 Nov 2026

Model access is built in

Added

Dashboard

  • Settings no longer asks for an API key. Model access is built into idk.

Chat

  • Questions use the sealed model key. That key is not saved in settings and is not shown on screen.

Bug fixes

Dashboard

  • Dashboard buttons and chat rows open again. A font helper was stopping the click.
v0.1.0 2 Nov 2026

A license for this computer

Added

Setup

  • idk installs from a Windows setup file and shows the license before setup finishes.
  • A license is $5.99 once for this computer. Copying the app or the license file does not unlock another computer.

Dashboard

  • Settings can buy a license for this computer and shows when this computer is already paid.

Chat

  • Asking waits until this computer is licensed.
